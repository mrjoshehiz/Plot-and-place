# Plot & Place design direction

Apply the studied references as a coherent product: Elyse for cinematic architectural imagery and bold Cormorant display type; RealNest for calm rounded cards, restrained charcoal-blue selection, and readable sans-serif product information; the desktop map/catalogue references for a filter rail and list/map organization; the configurator reference for a large preview alongside grouped visual choices.

Home, discovery, property details, design and investment are dedicated hash-addressable views. Home opens with architectural photography and an editorial headline, then a search strip, featured homes, and a design invitation. Discovery uses uniform photographic cards, a desktop filter rail, mobile expandable filters, categories, result counts and honest empty states. Property details give price, facts, gallery and inspection context their own full page.

The design workspace pairs a large reference preview with Plot & layout, Exterior, Interior and Outdoors steps. Materials use labelled swatches; other options use visible selectable cards. A summary saves a design brief on the current device and restores valid choices on reopening. Images remain reference concepts, not generated personalized results.

Palette: chalk #f4f4f1, white surfaces, charcoal #1d2730, muted ink #606970, and restrained teal #254b59. Locally served Cormorant headlines and Albert Sans controls. Cards use 24px outer and 16px inner radii with 10px photographic insets. Mobile uses labelled bottom navigation with reserved viewport space so it cannot cover controls. Major headings reflow without horizontal overflow.

Accessible focus, semantic labels, selected states, Radix dialogs, 44px touch targets and reduced-motion behavior accompany restrained hover and press feedback. Existing owner access, records, media uploads and calculators are preserved. Keep sample data, document verification, regional maps and unavailable services clearly described.

Use one clear opening eyebrow, upright Cormorant display text, and uniform featured catalogue cards. Avoid ornamental rules around every metadata row; group facts in soft capsules. Design choices use distinctive architectural sketches. Guest actions explain sign-in before requesting input. Regional orientation uses lazy Leaflet raster tiles with attribution and a recoverable failure state.

Motion: one architectural-image settle on entry, staged headline/actions, one-time viewport reveals, and fast page/design-step transitions. The explicitly requested middle home-inspiration carousel glides continuously with pause, hover and focus controls. The homepage walkthrough loops silently with a visible pause control, stops offscreen, and defaults to a still for reduced motion. Reduced motion keeps all content visible and motion-free; keyboard navigation reveals sections immediately.
